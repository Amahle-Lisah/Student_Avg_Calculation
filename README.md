## Project Title
Student Average Mark Calculator

## Author
**Amahle Lisah Khumalo**

## Overview
A simple Java console application that calculates a student's average mark. The user enters four marks, and the program works out the average and displays it.

## What the Program Does
1. Asks the user to enter four marks, one at a time.
2. Adds the four marks together.
3. Divides the total by 4 to calculate the average.
4. Displays the result on the screen.
